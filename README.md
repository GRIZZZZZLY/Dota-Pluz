# Dota-Pluz

**Dota 2 Copilot** — личный помощник для Dota 2, который работает на вашем компьютере. Он подсказывает
героя на драфте, следующий скилл, талант и предмет, считает таймеры и остаток золота, а после матча
разбирает игру. Данные о матче приходят только от самой Dota через официальный канал Valve
**Game State Integration** (GSI) и из публичного API OpenDota. Процесс игры приложение не трогает.
Подробно — в [docs/SAFETY.md](docs/SAFETY.md).

![Страница Live во время демо-матча: таймеры, статистика героя, следующие предметы](docs/screenshots/live.jpg)

## Что умеет

| Часть | Что делает |
|---|---|
| **Copilot** | Советует следующий скилл, талант, основной, ситуативный и защитный предмет, напоминает о выкупе. Каждый совет проходит проверку: не куплен ли предмет, есть ли свободное очко, подходит ли уровень. Все советы пишутся в журнал: последовал игрок совету или нет |
| **Подсказки поверх Dota** | Три маленьких окна — скилл, пики, предметы. Видны, только когда есть подсказка, клики проходят в игру. Ручка двигает окна, меняет прозрачность и открывает полное приложение на втором мониторе |
| **Сборки для Turbo** | Раз в день собирает публичные Turbo-игры игроков Divine и выше: стартовые предметы, первые крупные и финальные, с размером выборки. Режим Turbo определяется сам по пассивному золоту после горна |
| **Драфт** | Пики в целом и по позициям, баны, контрпики к каждому врагу, оценка шанса на победу, слабые места команды. Свой герой, союзники и баны приходят из GSI. Пики врагов можно ввести вручную или прочитать с экрана драфта |
| **Чтение экрана драфта** (по желанию) | Отдельная программа `d2bg-cv` узнаёт героев на экране драфта. Снимает экран только во время драфта настоящей игры, кадры не сохраняет |
| **Live** | Таймеры на ближайшие 5 минут: руны, лотос, Tormentor, нейтральные предметы, Рошан. K/D/A, GPM, золото, сколько не хватает на следующий предмет и когда он будет |
| **Heroes, Items, Meta** | Pro-сборки, порядок скиллов и таланты, тайминги предметов, матчапы, мета по медалям |
| **Profile, Matches** | Профиль игрока, пул героев, разбор матча с вашими таймингами против pro |
| **`/compact`** | Компактная страница для второго монитора или телефона: советы Copilot, причина, недостающее золото, «Как купить» |

## Запуск на Windows

Нужны [uv](https://docs.astral.sh/uv/) (`winget install astral-sh.uv`) и Node.js 20 или новее (только
для первой сборки интерфейса).

```bash
.\run.cmd
```

Скрипт ставит Python-пакеты, при необходимости собирает интерфейс, запускает приложение на
<http://127.0.0.1:4242> и открывает браузер. `Ctrl+C` останавливает.

Первый запуск с Dota:

1. На странице **Setup** нажмите **Install**. Приложение запишет один файл в папку Dota:
   `game\dota\cfg\gamestate_integration\gamestate_integration_d2bg.cfg`.
2. Запустите Dota 2. Setup станет зелёным, когда придут первые данные.
3. Если за минуту ничего не пришло, добавьте `-gamestateintegration` в параметры запуска Dota в Steam
   сами. Приложение параметры запуска не меняет.

Без Dota: кнопка **Play a demo match** на странице Live или `.\run.cmd --demo juggernaut`. Демо-матч
выдуманный, страница об этом пишет.

Дополнительно, рядом с работающим `run.cmd`:

| Файл | Что запускает |
|---|---|
| `run-overlay.cmd` | Подсказки поверх Dota. Нужен режим окна Borderless. `run-overlay.cmd --app` ещё открывает приложение на втором мониторе |
| `run-cv.cmd` | Чтение экрана драфта. Перед первым запуском один раз: `uv sync --extra cv` |

## Командная строка

```bash
uv run d2bg serve                 # приложение (его запускает run.cmd)
uv run d2bg draft --enemy "pa, lion, invoker" --ally "cm, axe"
uv run d2bg build invoker         # pro-сборка текстом
uv run d2bg data refresh          # обновить данные OpenDota, включая сборки Turbo
uv run d2bg data status
uv run d2bg gsi status            # ещё: gsi install, gsi remove
uv run d2bg-cv templates          # один раз: портреты героев для чтения экрана
uv run d2bg-cv snap               # сохранить один кадр драфта для калибровки
```

## Безопасность

| Приложение трогает | Как |
|---|---|
| Один файл GSI-конфига в папке Dota | Пишется по кнопке Install, удаляется по кнопке Remove |
| `libraryfolders.vdf` Steam и значение `SteamPath` в реестре | Только чтение, чтобы найти Dota |
| `127.0.0.1:4242` | Сюда Dota присылает состояние игры, отсюда браузер грузит интерфейс |
| `api.opendota.com` | Публичный API, не чаще одного запроса в секунду, с кэшем на диске |
| Главный монитор | Только `d2bg-cv`, только во время драфта настоящей игры |

Приложение не читает и не пишет память игры, ничего не внедряет и не рисует внутри игры. Оно не
нажимает клавиши и не кликает за игрока, не меняет файлы игры и настройки Steam. Подсказки поверх
Dota — обычные отдельные окна. Тесты `tests/d2bg/test_safety.py` и `tests/d2bg/test_cv_safety.py`
проверяют эти запреты.

## Как устроено

```
Dota 2 ──GSI──▶ /gsi ──▶ разбор ──▶ живой движок ──▶ Copilot: контекст ▶ кандидаты ▶ проверка ▶ журнал
                                         │                                         │
                                         └──▶ запись игры (.jsonl.gz)              └──▶ /compact, подсказки поверх Dota
d2bg-cv (по желанию) ──▶ пики с экрана драфта ──▶ драфт
OpenDota API ──▶ снимок данных + ежедневное обновление ──▶ драфт, сборки, Turbo, таймеры ──▶ веб-интерфейс
```

- **Python 3.12**: FastAPI, Pydantic, httpx, Typer, SQLite для журнала советов.
- **Интерфейс**: React 19, TypeScript, Vite.
- **Чтение экрана**: mss, OpenCV, numpy — только в отдельной программе `d2bg-cv`.

Устройство слоя Copilot — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Этапы работы —
[docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md). Техническое задание —
[DOTA2_COPILOT_TZ.md](DOTA2_COPILOT_TZ.md).

## Ограничения

1. В рейтинговом драфте GSI не присылает игроку пики врагов. Их читает `d2bg-cv` с экрана или игрок
   вводит вручную. Точность чтения на настоящих экранах драфта ещё не измерена.
2. Какой из двух талантов выбрал игрок, GSI не сообщает. Такой совет в журнале остаётся «неизвестно».
3. Сборки берутся из pro-игр и Turbo-игр сильных игроков. У редких героев выборка маленькая, страницы
   это показывают.
4. Оценка шанса на победу в драфте — скромная модель, это ориентир, а не приговор.
5. Таймеры сверены с патчноутами до 7.41f.
6. В игре ещё не проверены перетаскивание окон подсказок и окно на втором мониторе.
